# Attributed commit-summary boundary

The 24 October 2026 owner-run fixture preserves a real source and two saved outputs, with their original hashes. The run stopped before its third provider call. It is not a completed draft, and no test in this patch resumes that production run.

A one-line commit summary establishes a repository record and its attributed message, not implementation correctness, tested access controls, security benefits, author intent or personal learning. Imported-source prompts no longer inherit the personal capsule's six supported assertions or ask Story Miner to invent a learning-story angle. Owner-note and legacy capsule contracts remain separate.

The title-only checker adds narrow hard findings for observed learning/intent inferences and affirmative capability assertions. Explicit Verbatim evidence sections must contain copied source lines, not combined metadata, paraphrases or an inferred Scope. These findings require correction; they cannot be accepted as wording-only reviews. The checks are conservative heuristics, not complete semantic verification, and do not certify any unflagged sentence.

Existing source/artifact bytes, hashes, decisions, clearance, budgets, exact-task execution controls and per-post owner approval are unchanged. There is no new paid call, automatic revision, retry, schedule or publishing permission. Privacy matching is a separate repair; fixing a lexical false positive does not make the observed content grounded or publishable.

Validation uses the exact failed-run fixture, adversarial and positive source-grounding cases, and a six-checkpoint mocked workflow. Tests do not transmit the repository or any artifact to a provider. Real model output quality after these prompt changes remains untested until a separately authorized future run.
